# Finance read-only integration
The two source files are existing Office XLSX files, not native Sheets. The API reads metadata and streams original bytes through Google Drive API; it does not parse or recalculate cells, write files, or store copies. No file IDs or credentials in source control.
Configure server-only environment variables NKH_FINANCE_GOOGLE_CLIENT_EMAIL, NKH_FINANCE_GOOGLE_PRIVATE_KEY, NKH_FINANCE_FEES_FILE_ID, NKH_FINANCE_ACCOUNTS_FILE_ID. Create a dedicated Google Cloud service account, enable Drive API, grant Viewer access only to the two workbooks (no domain-wide delegation). Set IDs privately in hosting environment. Never use NEXT_PUBLIC variables. Redeploy after configuration.
All requests require active Master authorization; no caching, no arbitrary file IDs, no write methods. Test unauthorized, disabled staff, supervisor/team, unconfigured credentials, both downloads, and verify original file checksums. Downloads are local editable copies; source remains read-only. Financial tables, formula evaluation and reconciliation remain future work. Existing legacy session security limitations still apply.
