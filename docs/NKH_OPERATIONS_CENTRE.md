# Operations Centre
Master-only read-only summary uses existing property, calendar, task, audit event, roster and shift session tables via existing Supabase server helper. No mutations, refresh jobs, reservation changes or migrations. Colombo dates: today plus six days. Counts are room booking rows excluding Cancelled, not unique reservations or guests. Configured properties only; Google Sheet records may be stale. Each query capped at 500, with explicit cap warnings; unavailable sources return null. Audit queue includes all existing unresolved events, not only connected hotels. Task handover is a read-only open-task list, not a signed shift handover. Existing workspace links retained. Test authorization, partial failures, caps, date boundaries, stale sync and existing navigation before production reliance.
