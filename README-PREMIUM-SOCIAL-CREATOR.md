# NKH Social Media Creator — Premium Template Upgrade

This package upgrades the already-working Social Media Creator. It does not change the property API, OpenAI API route, database or environment variables.

## Replace these paths

- `app/components/reservation-tools/SocialMediaCreatorTool.tsx`
- `app/styles/components/social-media-creator.css`

## New features

- 12 professional hotel layout templates
- Six controlled hotel colour palettes
- Portrait, square, story and landscape formats
- Real-time preview after content generation
- Photo zoom, horizontal focus and vertical focus
- Adjustable overlay strength
- Optional hotel logo
- Optional public phone, WhatsApp or website line
- Exact-text poster rendering
- PNG download and caption copying
- Responsive desktop and mobile workspace

## Push

```powershell
git add app/components/reservation-tools/SocialMediaCreatorTool.tsx app/styles/components/social-media-creator.css
git commit -m "Upgrade social media creator with premium templates"
git push origin main
```
